# VINNYSTORE · Vitrine conceitual

Prévia de uma página para apresentar roupas, calçados e kits da VinnyStore. O visitante pode alternar entre três estruturas de navegação: Editorial, Loja direta e Lookbook. A escolha fica salva no navegador.

## Estado desta prévia

- As imagens são fotografias de referência licenciadas via Pexels, não fotos do estoque da VinnyStore.
- As peças são referências visuais. Não existem preços, estoque, tamanhos ou promessas de entrega inventados nesta página.
- O cabeçalho e o rodapé levam ao catálogo do WhatsApp informado pela loja: https://wa.me/c/5515996050317. Os cartões levam à conversa no mesmo número para confirmar detalhes.
- A página é um protótipo estático, sem carrinho, pagamento ou integração de estoque.

## Rodar localmente

Abra index.html em um navegador ou sirva a pasta com python -m http.server 8767.
